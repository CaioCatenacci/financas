# Painel de regras aprendidas no app

> Origem: BACKLOG B2 (P2) · spec Inc 2 §10. Rascunho do assistente em 2026-09-26 a partir da linha do BACKLOG; Problema, Valor e DoD são ponto de partida, não definição.

## Problema

As associações aprendidas (contraparte → categoria) não são visíveis nem editáveis no app. Para corrigir uma regra errada é preciso fazer uma correção nova ou rodar os tools Python.

## Valor

Ver, editar e remover as regras que o classificador usa, na aba Ajustes, sem sair do app.

## Pronto quando (DoD)

- [ ] a aba Ajustes lista as associações (chave, tipo, categoria, subcategoria, n, atualizado em), em ordem de `atualizado_em` decrescente
- [ ] a chave de `tipo_chave='pix_cpf'` aparece só com os 4 últimos caracteres (ex.: `••••1234`); a de `tipo_chave='nome'` aparece inteira
- [ ] uma busca por texto filtra a lista
- [ ] dá para trocar a categoria/subcategoria de uma associação, e a próxima captura e o próximo import dessa contraparte usam a nova
- [ ] dá para remover uma associação, e a próxima captura dessa contraparte volta para a sugestão do modelo
