# Guardar o PDF original do extrato/fatura

> Origem: BACKLOG C4 (P3) · spec upload-tela §7. Rascunho do assistente em 2026-09-26 a partir da linha do BACKLOG; Problema, Valor e DoD são ponto de partida, não definição.

## Problema

No import só o texto do PDF é usado; o arquivo original se perde.

## Valor

Ter o documento de origem de cada import, como já acontece com os comprovantes no Dropbox.

## Pronto quando (DoD)

- [ ] depois de um `aplicar` bem-sucedido na aba Importar, o app envia o arquivo original numa rota nova `POST /api/importar/arquivo` (corpo = bytes do arquivo; tipo, banco e período na query) e o Worker sobe para o Dropbox; falha no envio não desfaz o import, só mostra "o import entrou, mas o arquivo original não foi guardado"
- [ ] caminhos e nomes (função pura em `worker/dropbox_nome.js`, com teste): extrato → `/Finanças/Extratos/<banco>/AAAA-MM-DD_a_AAAA-MM-DD_<banco>_extrato.pdf` (de/até do período importado); fatura → `/Finanças/Faturas/<banco>/AAAA-MM_<banco>_fatura.pdf` (mês de vencimento); Wise → `/Finanças/Extratos/wise/AAAA-MM-DD_a_AAAA-MM-DD_wise_extrato.csv`; `<banco>` é `itau`, `c6` ou `wise`
- [ ] reimportar o mesmo período sobrescreve o arquivo (upload com `mode: overwrite` para essa rota; os comprovantes seguem com `add` + `autorename`)
- [ ] o PDF do C6 vai como veio, ainda protegido pela senha (o Worker não abre nem decifra)
- [ ] a rota confere o token como as outras `/api/*` e recusa tipo/banco fora do vocabulário e arquivo acima de 20 MB
- [ ] testes: nome/caminho dos três tipos, rota com Dropbox falso (sobe no caminho certo com overwrite; vocabulário inválido → 400), e o app chama a rota só depois do `aplicar` dar certo

## Exemplo

Extrato Itaú de 03/09/2026 a 13/10/2026 → `/Finanças/Extratos/itau/2026-09-03_a_2026-10-13_itau_extrato.pdf`. Fatura com vencimento em outubro/2026 → `/Finanças/Faturas/itau/2026-10_itau_fatura.pdf`. Reimportar o mesmo extrato → o mesmo arquivo é substituído, sem "(1)" no nome.

## Fora

- Mudar a estrutura dos comprovantes no Dropbox (`/Finanças/Comprovantes/...`): fica como está.
- Guardar o arquivo de quem só abriu a prévia e não gravou.
